# Радар Скидок — автопостинг в Telegram

Публикует скидки на игры в канал по расписанию (МСК):
10:00 — дайджест из 5, 15:00 — одна находка, 18:00 — статистика владельцу, 21:00 — подборка из 3.

Одна игра — один пост: обложка, название, цена в рублях, размер скидки, ссылка в Steam.

## Настройка
Секреты репозитория (Settings → Secrets and variables → Actions):
- `TELEGRAM_TOKEN` — токен бота
- `CHANNEL_ID` — id канала (`-100…`) или @username
- `OWNER_CHAT_ID` — твой личный chat_id для статистики

Ручной запуск: Actions → deal-radar → Run workflow → выбрать режим.
